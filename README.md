# 📱 Mobile Sales & Profit Analysis Dashboard | Power BI

## 📌 Project Overview

This project features an interactive Power BI dashboard designed to analyze mobile phone sales, profitability, brand performance, product configurations, payment methods, and geographical sales distribution.

The dashboard brings key sales metrics together to support performance monitoring and business analysis.

## 🎯 Project Objectives

- Monitor overall sales, profit, and profit margin.
- Compare sales performance across mobile brands.
- Analyze profit contributions by brand.
- Explore sales by RAM and storage capacity.
- Examine payment method distribution.
- Track monthly sales trends.
- Analyze geographical sales distribution across Indian states.
